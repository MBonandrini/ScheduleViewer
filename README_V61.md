# Schedule Studio Professional v6.1

Single-user Primavera P6 20.x-style scheduling, editing, analysis and forensic project-controls workbench.

## Main v6.1 change

The P6-style menus, toolbar and keyboard shortcuts now use one central command architecture rather than separate UI-only handlers. Day-one planner commands are functional from each supported command surface.

P6 Professional 20.x is the default scheduling compatibility profile. Calculation behavior remains configurable through Schedule Options and Advanced Settings.

After F9, the application can compare its calculated ES/EF/LS/LF/float against the values originally imported from P6. Imported values are preserved as evidence rather than silently treated as identical to the independent engine result.

See `P6_COMMAND_MATRIX.md` and `P6_GOLDEN_VALIDATION_PLAN.md`.
