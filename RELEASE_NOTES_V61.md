# v6.1 Release Notes

- P6 20.x is now the default compatibility target.
- Added centralized P6 command registry.
- Unified menu, toolbar and keyboard dispatch.
- Added functional Ctrl+O, Ctrl+S, Ctrl+F, Ctrl+C/V, Insert/Delete, F9 and Gantt zoom shortcuts.
- Added P6-style Schedule Options modal.
- Added Resource Leveling Options command.
- Added imported-P6-versus-calculated date/float discrepancy report.
- Added activity copy/paste carrying assignments, codes, UDFs and notebooks while clearing actual dates.
- Allowed external predecessor relationships to activities in another project already loaded in the model.
- Added stable command IDs for planned P6 functions so future workflows can be integrated without redesigning the command layer.
