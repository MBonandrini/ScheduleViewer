# v6.0 Release Notes — P6-style Single-User Desktop

## Main UX changes

- Removed the long left sidebar.
- Added desktop title bar, application menu, compact command toolbar, primary module tabs and bottom status bar.
- Rebuilt Activities around the classic planning workflow: WBS/activity grid + Gantt + bottom Activity Inspector.
- Added draggable activity-grid/Gantt splitter and synchronized vertical scrolling.
- Added P6-inspired green normal bars, red critical bars, blue Data Date line, black WBS summary bars, baseline/progress/actual layers and squared relationship connectors.
- Added Gantt zoom controls.
- Reworked EPS/Projects into a project table plus high-level project Gantt.

## Single-user P6-style tool exposure

Menus and module tabs now expose Projects/EPS, Activities, WBS, Relationships, Resources, Roles, OBS, Calendars, Activity Codes/UDFs, Cost Accounts, Resource Curves, Risks, Issues, Work Products/Documents, Baselines, F9 Schedule, Resource Leveling, Progress/EVM, Layouts/Filters, Compare, Trace Logic, Forensic Intelligence, Health/Risk, Trends/Forecast, Reports, Search, BIM/4D and project packages.

Multi-user administration, security profiles, team access control and server administration are intentionally excluded.

## Activity Inspector

General, Status, Dates, Relationships, Resources, Expenses, Codes, Constraints, Notebooks, Steps, Risks, Trace Logic and Raw Data.
